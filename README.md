# Projects SPA

**Projects SPA** — это молниеносное, работающее полностью в браузере (offline-first) одностраничное приложение для управления проектами, задачами и изменениями (багами/фичами).

Приложение спроектировано с упором на максимальную производительность, отсутствие сложных сборочных конвейеров (zero-build) и полный контроль пользователя над своими данными.

## 🌟 Ключевые возможности

- **100% Локальное хранение**: Все данные хранятся прямо в вашем браузере с использованием IndexedDB. Никаких серверов, облачных подписок и задержек сети.
- **Автосохранение в файл**: Поддержка современного *File System Access API* позволяет привязать локальный `.json` файл на вашем компьютере, в который приложение будет автоматически сохранять резервную копию при каждом изменении.
- **Три режима просмотра**:
  - 📋 **Таблица**: Плотный и информативный вид с поддержкой сортировки и раскрывающихся списков (задачи внутри проектов).
  - 🛹 **Канбан-доска**: Удобное управление статусами с помощью Drag & Drop. Поддержка кастомных досок.
  - 📊 **Таймлайн (Диаграмма Ганта)**: Визуальное планирование сроков и дедлайнов.
- **Резервное копирование**: Экспорт и импорт всей базы данных в один клик.
- **Быстрые действия**: Удобные функции дублирования задач, конвертации изменений в задачи и наоборот.

## 🛠 Технологический стек

Проект написан без использования тяжеловесных фреймворков:
- **Core**: Vanilla JavaScript (ES Modules), HTML5, CSS3.
- **База данных**: [Dexie.js](https://dexie.org/) (удобная обертка над нативным IndexedDB).
- **Архитектура**: Глобальный State Management, кастомный Event Bus, Hash-роутинг.

## 🚀 Запуск проекта

Так как проект не использует сборщики (Webpack, Vite и т.д.), для его запуска достаточно любого простейшего статического сервера.

1. Клонируйте репозиторий или скачайте исходный код.
2. Откройте папку проекта в терминале.
3. Запустите любой локальный веб-сервер. Например:
   - Использование Node.js: `npx serve .`
   - Использование Python 3: `python -m http.server`
   - Использование PHP: `php -S localhost:8000`
4. Откройте в браузере локальный адрес (например, `http://localhost:3000`).

*(Примечание: Вы также можете использовать расширения вроде "Live Server" для VS Code).*
